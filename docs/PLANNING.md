## 1. 서비스 개요 및 기획 배경

### 1.1 기획 배경
* **전통주 시장의 급성장**: 최근 2030 세대를 중심으로 개성 있는 로컬 전통주와 프리미엄 막걸리에 대한 관심이 급증하고 있습니다.
* **정보 탐색의 어려움**: 전국에 1,000여 종이 넘는 막걸리가 존재하지만, 대중은 마트에서 흔히 보이는 몇 가지 브랜드 외에는 자신의 입맛에 맞는 전통주를 찾기 어렵습니다.
* **페어링(마리아주) 고민**: "이 막걸리는 어떤 안주와 먹어야 맛있을까?"에 대한 정보가 흩어져 있어 구매 결정이 지연됩니다.

### 1.2 문제 정의 (Problem Statement)
1. **취향 매칭의 부재**: 단맛, 신맛, 탄산감, 담백함 등 개인 취향에 맞는 막걸리를 추천해 주는 직관적인 큐레이션 도구 부족.
2. **지역성 한계**: 여행지나 로컬 명주를 찾고 싶어도 지역별 전통주 데이터에 쉽게 접근하기 어려움.
3. **사용자 참여 공간 부족**: 사용자가 직접 경험한 숨겨진 명주와 꿀조합 안주를 다른 사람들과 공유할 수 있는 커뮤니티 부재.

### 1.3 서비스 정의 (Solution)
* **AI 주모 큐레이션**: 한국 전통 주막의 정겨운 '주모' 페르소나를 탑재한 AI가 사용자의 지역과 맛 취향을 반영하여 **실제로 존재하는 막걸리 1종과 찰떡궁합 안주 1~2종을 확정 추천**.
* **주모의 비밀 장부**: 방문자들이 자신이 알고 있는 인생 막걸리 조합을 제보하고, 모든 방문자가 실시간으로 공유할 수 있는 **온라인 클라우드 방명록**.

## 3. 핵심 가치 제안 (Value Proposition)

1. **실존 명주 보장 (Hallucination Free)**:
   * AI가 가상의 이름을 지어내지 않고, 실제 양조장에서 생산되는 진짜 전통주만 엄선하여 추천합니다.
2. **직관적인 비주얼 카드 인터페이스**:
   * 복잡한 텍스트 입력 대신 5가지 직관적인 이모지 카드(🍯 달달함, 🍋 새콤함, ⚡ 톡 쏘는 탄산, 🌰 담백함, 🎯 아무거나 좋아요)로 최대 3개까지 직관적으로 선택합니다.
   * `🎯 아무거나 좋아요` 선택 시 단독 선택 모드로 전환되어 선택 장애가 있는 사용자에게 최고의 편의성을 제공합니다.
3. **구수한 주모 페르소나 & 정형화된 4단계 답변**:
   * 사극 주모 톤으로 친근감을 주며, [인사/취향 확인 → 막걸리 추천 & 테이스팅 노트 → 어울리는 안주 2종 → 서울/수도권 구매처 안내]의 정돈된 서식으로 가독성을 극대화합니다.
4. **영구 보존되는 실시간 비밀 장부**:
   * Firebase Firestore 클라우드 NoSQL DB 연동으로 새로고침해도 사라지지 않는 실시간 전국 방명록을 제공합니다.
5. **사용자 친화적 피드백 및 검증**:
   * 브라우저 alert 대신 화면 중앙 주막 테마 커스텀 모달 적용, 한글 지명 정규식 검증 및 허구 지명에 대한 재입력 유도 피드백을 제공합니다.

## 4. 정보 구조도 (Information Architecture - IA)

```text
오늘의 주막 (today-jumak)
│
├── [메인 페이지: index.html]
│   ├── 상단 네비게이션 바 (주막 소개 / AI 추천받기 / 비밀 장부)
│   ├── 서비스 소개 섹션 (#intro)
│   ├── AI 막걸리 추천 섹션 (#ai-feature)
│   │   ├── 지역 입력 필드 (Text Input, 한글 2~15자 유효성 검사)
│   │   ├── 5종 맛 선택 카드 (🍯, 🍋, ⚡, 🌰, 🎯 아무거나 좋아요)
│   │   ├── 추천 요청 버튼 ("주모! 추천해 주시오 🛎️")
│   │   └── AI 추천 결과창 (#result-box, 4단계 포맷 & <b> 강조)
│   └── 인생 막걸리 제보 섹션 (#report-form)
│       ├── 막걸리 이름 & 안주 입력 필드
│       ├── 제보하기 버튼 (Firestore 저장 + 커스텀 모달 피드백)
│       └── 비밀 장부 바로가기 배너 버튼
│
└── [비밀 장부 전용 페이지: ledger.html]
    ├── 상단 헤더 & 네비게이션 (AI 추천받기 / 나도 제보하기)
    ├── 실시간 제보 통계 배지 (총 N개의 비법 조합)
    └── 한 줄 리스트 목록 (#ledger-list)
        └── [#제보번호 | 🍶 막걸리명 ＋ 🥢 안주명 | 📅 등록일시]
```

## 5. 상세 기능 명세서 (Functional Specifications)

### 5.1 AI 추천 엔진 (Backend: Python Flask + Vercel Serverless)
* **엔드포인트**: `POST /api/recommend`
* **요청 파라미터**: `{ "region": "속초", "taste": "달달한 맛, 탄산이 강한 맛" }` 또는 `{ "region": "서울", "taste": "아무거나 좋아요" }`
* **응답 포맷**: `{ "result": "HTML <b> 태그 및 줄바꿈이 포함된 주모 추천 텍스트" }`
* **입력 검증 (Validation)**:
  * 한글 2~15자 정규식(`/^[가-힣\s]{2,15}$/`) 검증으로 영문 오타, 숫자, 특수기호, 단독 자모 원천 차단.
  * 실존하지 않는 허구의 지명 입력 시 AI 주모의 "금시초문이오" 재입력 안내 팝업 출력.
* **프롬프트 규칙**:
  1. 질문/되묻기 절대 금지, 즉시 추천 확정.
  2. 실존 막걸리 1종 + 어울리는 안주 2종 및 궁합 이유.
  3. 서울/수도권 구매 가능 여부 포함.
  4. 막걸리 및 안주명은 `<b>` 태그로 굵게 표시.
  5. `아무거나 좋아요` 선택 시: "어떤 맛이든 다 좋소" 요청으로 자연스럽게 분기하여 해당 지역의 최고 명주를 자율 추천.

### 5.2 제보하기 & 주모의 비밀 장부 (Frontend + Firebase Firestore)
* **데이터 모델 (`reports` 컬렉션)**:
  ```json
  {
    "name": "string (막걸리 이름)",
    "food": "string (어울리는 안주)",
    "createdAt": "timestamp (서버 등록 시간)"
  }
  ```
* **이중 안전장치 및 UX**:
  * 제보 클릭 즉시 `localStorage`에 0초 만에 백업 반영 (낙관적 UI).
  * Firestore 저장 시 2.5초 타임아웃을 적용하여 무한 대기 방지.
  * 브라우저 기본 경고창 대신 **화면 중앙 주막 커스텀 모달** 팝업 표시.

## 6. 화면 설계 및 와이어프레임 명세

### 6.1 메인 화면 (`index.html`)
* **레이아웃**: 모바일 퍼스트 반응형 레이아웃 (`max-width: 600px`, 중앙 정렬)
* **컬러 팔레트**:
  * 메인 포인트: `#d97736` (주막 황토빛 주황)
  * 딥 포인트: `#8b4513` (전통 가구 짙은 갈색)
  * 배경: `#fffdfa` (부드러운 한지 미색)
  * 결과 박스: `#fff3cd` (달콤한 막걸리빛 옐로우)
* **주막 커스텀 모달**:
  * 화면 정중앙 반투명 오버레이 및 둥근 카드형 팝업 UI.
  * 이모지 아이콘, 주막 폰트, 호탕한 주모 어투 안내.

### 6.2 비밀 장부 화면 (`ledger.html`)
* **테이블형 한 줄 리스트(Single-line Row)**:
  * 각 행마다 `#번호`, `🍶 막걸리명 ＋ 🥢 안주명`, `일시`가 한 줄에 정갈하게 정렬.
  * 마우스 호버 시 `#fcf9f4` 하이라이트.

## 7. 기대 효과 및 향후 발전 방향 (Roadmap & BM)

### 7.1 기대 효과
* 사용자는 고민 없이 3초 만에 오늘 밤의 술상을 결정할 수 있습니다.
* 지역 양조장 및 전통주 소상공인들의 명주가 자연스럽게 홍보되는 상생 생태계 조성.

### 7.2 단계별 구현 현황 및 로드맵
* **Phase 1 (구현 완료)**: 
  * AI 주모 4문단 추천 엔진 (`gpt-5-mini` 모델 호출).
  * 5종 이모지 맛 카드(🍯, 🍋, ⚡, 🌰, 🎯 아무거나 좋아요) 및 상호 전환 인터랙션.
  * 한글 지명 정규식 검증 및 허구 지명 예외 안내.
  * 주막 테마 화면 중앙 커스텀 모달 시스템.
* **Phase 2 (구현 완료)**: 
  * Firebase Firestore 클라우드 NoSQL 실시간 연동.
  * 비밀 장부 전용 독립 페이지 (`ledger.html`) 분리 및 한 줄 리스트(Single-line row) 테이블 UI.
  * 낙관적 UI 업데이트 (0초 로컬 백업) & 2.5초 타임아웃 안전장치.
* **Phase 3 (차기 예정)**: 
  * 소셜 공유 기능: 카카오톡 및 인스타그램 스토리 추천 결과 즉시 공유.
* **Phase 4 (차기 예정)**: 
  * 위치 기반 지도 API 연동: GPS 기반 반경 10km 이내 전통주점 및 판매처 탐색.
* **Phase 5 (차기 예정)**: 
  * 양조장 스마트스토어 및 전통주 커머스 플랫폼 직접 구매 링크 제휴.
